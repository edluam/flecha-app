# Flecha techos suspendidos

App del móvil del captador de flecha (ensayo VA074). Solo la pantalla de
captura: no contiene datos del laboratorio. El original vive en
`edluam/BD_ICINCO_NUEVA` (`app_movil_flecha/`); este repo existe solo para
servirla por https con GitHub Pages, que es lo que exige el Bluetooth de Chrome.

Abrir en Chrome de Android: https://edluam.github.io/flecha-app/
Modo demostración: https://edluam.github.io/flecha-app/?demo
